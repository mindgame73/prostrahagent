# Уведомления о брошенных оформлениях (Инссмарт → Telegram)

`Code.gs` — веб-приложение Google Apps Script (аккаунт mindgame73rus@gmail.com).
Инссмарт вызывает его постбэком на шагах клиента в виджете, скрипт пишет в Telegram боту.

- В Telegram уходят только тип события, номер заказа, вознаграждение и время. Контакты клиента — в кабинете Инссмарт → «Расчёты и заявки».
- Свойства скрипта: `BOT_TOKEN` (токен от @BotFather), `CHAT_IDS` (через запятую; узнать функцией `findChats` после Start у бота).
- Проверка: функция `testAlert`.
- В кабинете Инссмарт: Виджет → Аналитика → Postback (Webhook): тип GET, адрес
  `<URL веб-приложения>?event={event}&orderId={orderId}&profit={profit}&dateTime={dateTime}`, события — оплата/ссылка на оплату/отмена/заявка.

После правки кода: Развертывание → Управление развертываниями → изменить → Новая версия (адрес не меняется).
